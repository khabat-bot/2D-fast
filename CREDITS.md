# Credits

This project uses the following third-party assets and libraries. When a
credit page is added to the game, this file is the source of truth.

---

## m6x11 — bitmap font

- **Asset:** m6x11 (6×11 pixel font, uppercase/lowercase, numbers, symbols)
- **Author:** Daniel Linssen
- **Source:** https://managore.itch.io/m6x11
- **License:** Free to use with attribution. See the itch.io page for the
  current terms. Attribution is required; commercial use is allowed.
- **Used in:** all in-game text (HUD, menus, results screen, debug labels)
- **Form:** converted from `m6x11.ttf` to BMFont format (`.fnt` + `.png`)
  for pixel-perfect rendering. The `.ttf` is the source file and is not
  shipped with the game; only the generated `.fnt`/`.png` are.
- **Attribution text (copy into the credit page):**
  > Font: m6x11 by Daniel Linssen — https://managore.itch.io/m6x11

## Adding new credits

attribution text to show on the credit page. Do not remove finished entries.
